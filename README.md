# Luminvue Medical website

Static one-page site for [www.luminvuehk.com](https://www.luminvuehk.com), hosted on GitHub Pages.

- `index.html`: the page (styles and script inline)
- `assets/`: favicon and images
- `CNAME`: the custom domain for GitHub Pages

To update the site, edit the files, commit and push to `main`. GitHub Pages republishes in about a minute.

Preview locally:

```
python -m http.server 8765
```
